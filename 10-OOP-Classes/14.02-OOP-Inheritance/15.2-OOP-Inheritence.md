A recap of Car class with a slightly different version:

- Use an arrow function for the method.
  - The advantage here is that it makes the syntax more concise.
  - Because the return value is implicit and there's only one line of logic, we can omit the curly braces and return keyword:
- Have a default class property:
  - A class can have properties which are not set by parameters. In this case they have default values assigned in the constructor
  - Give Car an additional property, 'onRoad', which is a boolean, with a default value of true.

```
    class Car {
```

### Class Inheritance:

A Class can be declared that inherits all the methods and properties of another, parent, class. The **extends** keyword is used to express this relationship. In addition to the constructor method, the child class has a **super()** method that takes all the parameters unique to the new parent class.

Let's start with a class, `Player`, with two properties, `name` and `energy`. Only `name` has a parameter to set. The `energy` property haw a default value of 100, so no parameter to set.

```
    class Player {

        constructor(name) {
            this.name = name;
            this.energy = 100;
        }
    }
```

Give the class two methods: `introducePlayer`, which returns a string and `restPlayer` that sets the energy level and announces the update.

```
    class Player {

        constructor(name) {
            this.name = name;
            this.energy = 100;
        }

        introducePlayer() {
            return `Player name: ${this.name}\nGame on!`;
        }

        restPlayer() {
            let energy = this.energy;
            this.energy += 10;
            return `Player rested..\nEnergy increased from ${energy} to ${this.energy}.`;
        }

    }
```

Instantiate an object of the `Player` class and test out its properties and methods:

```
    let player = new Player('Wezzul');

    console.log(player.name);
    console.log(player.energy);
    console.log(player.introducePlayer());
    console.log(player.restPlayer());
```

**extending an existing class**

Now for the inheritance part. We'll make a new class called `Warrior` which extends Player. This means that `Warrior` will start off with all the properites and methods of `Player`. On top of that, `Warrior` will have its own unique properites and methods.

Declare a new class with the syntax `class Warrior extends Player`:

```
    class Warrior extends Player {
    }
```

The constructor has two parameters: - `name` : the inherited parameter from the Player - `weapon` : unique parameter of the Warrior class

```
    class Warrior extends Player {
        constructor(name, weapon) {
        }
    }
```

**super()**
Classes that extend have an additional method besides the constructor, called `super()`. - `super()` goes inside the constructor. - `super()` has as its parameters all inherited properties that require arguments to be passed in.

```
   class Warrior extends Player {

   constructor(name, weapon) {
       super(name);
   }

   }
```

After `super()` method come the properties unique to the Warrior class. We'll keep it short and only have one propert: `weapon`:

```
    class Warrior extends Player {

    constructor(name, weapon) {
        super(name);
        this.weapon = weapon;
    }

    }
```

Give the Warrior class its own method, `attack()`. Based on the energy level, it returns a message announcing an attack, or it says that it doesn't have enough energy to attack.

Each time the `attack()` method is called, the energy level decreases by 10. This is followed by an announcement of the lower energy level.

```
class Warrior extends Player {

  constructor(name, weapon) {
    super(name);
    this.weapon = weapon;
  }

  attack() {

    let msg = "";
    if (this.energy <= 0) {
      msg = `Not enough energy to wield the ${this.weapon}!`;
    } else {
      msg = `Warrior attacked with the ${this.weapon}!`;
    }

    let energy = this.energy;
    this.energy -= 10;
    msg += `\nEnergy decreased from ${energy} to ${this.energy}.`;
    return msg;
  }

}
```

Instantiate an instance of the Warrior class, passing in two arguments: name and weapon.

```
    const warrior = new Warrior("Konan", "Battle Ax");

    console.log(warrior.name);
    console.log(warrior.energy);
    console.log(warrior.weapon);
    console.log(warrior.introducePlayer());
    console.log(warrior.restPlayer());
    console.log(warrior.attack());
```

**ineriting inheritance**

A class can extend a class that extends a class.
Let's make another class, `SuperHero` that extends `Warrior`.

`SuperHero` will start out with everything the `Warrior` class has, which includes everything it inherited from the `Player` class.

We will give the `SuperHero` class its own property, `superPower`, as well as its own method `useSuperPower()`.

The `useSuperPower()` method is virtually identical to the `attack()` method, so you can copy-paste it:

    - If there is enough energy to use the superpower, the superpower is used and that fact is announced
    - Else, it says that it doesn't have enough energy to use the super power.
    - Also, as with `attack()`, calling the `useSuperPower()` method costs 10 units of energy.

The `super()` method now has two parameters, `name` and `weapon`, which it inherits from the `Player` and `Warrior` classes, respectively.

```
    class SuperHero extends Warrior {

        constructor(name, weapon, superPower) {
            super(name, weapon);
            this.superPower = superPower;
        }

        useSuperPower() {

            let msg = "";
            if (this.energy <= 0) {
            msg = `Not enough energy to use ${this.superPower}!`;
            } else {
            msg = `Super Hero used ${this.superPower}!`;
            }

            let energy = this.energy;
            this.energy -= 10;
            msg += `\nEnergy decreased from ${energy} to ${this.energy}.`;
            return msg;
        }

    }
```

Instantiate an instance of the `SuperHero` class, passing in the three arguments: `name`, `weapon` and `superPower`:

```
    const superhero = new SuperHero("Magami", "Battle Ax", "Super-Strength");

    console.log(superhero.introducePlayer());
    console.log(superhero.attack());
    console.log(superhero.restPlayer());
    console.log(superhero.superPower);
    console.log(superhero.useSuperPower());
```

### Prototype

The **prototype** keyword is used to add properties to a class.

Let's add a boolean property `wearsCape` to the `SuperHero` class.

```
    SuperHero.prototype.wearsCape = true;
```

Also add a method called `introduceSuperHero`:

```
    SuperHero.prototype.introduceSuperHero = function() {
    return `Behold! I am ${this.name}! I wield a fearsome ${this.weapon}, and I possess the incredible superpower of ${this.superPower}!`;
    }
```

Instantiate a new `SuperHero` object, which will have the new property `wearsCape` as well as the new method, `introduceSuperHero`.

